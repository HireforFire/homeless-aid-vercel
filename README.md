# Homeless Aid Finder

A simple Next.js + Vercel MVP that helps people quickly find:
- Shelter
- Food
- Hygiene services
- Public resources
- Clothing & supplies

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Vercel deployment
- Static JSON resource data for fast updates

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push to GitHub
2. Import the repo in Vercel
3. Deploy
